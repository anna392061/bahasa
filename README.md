# Bahasa · 印尼语单词学习 Web App

**为中文使用者设计的印尼语单词记忆工具。** 每天循序学习新词，结合间隔复习、真实语境、词根词缀、词族关联和日常口语，逐步建立印尼语词汇能力。

**在线体验：** https://anna392061.github.io/bahasa/  
无需安装即可在浏览器中使用。iPhone 用户也可以通过 Safari 的「分享 → 添加到主屏幕」把它当作桌面 Web App 使用。

## 为什么使用 Bahasa？

- **循序学习**：内置约 700 个由基础交流逐渐过渡到日常表达的印尼语词条；每日新词目标可调整。
- **间隔复习**：根据记忆表现安排复习，而不是反复随机刷词。
- **按词义学习**：不同常见含义分别展示；附中文解释、词性和双语例句。
- **固定搭配与句法结构**：学习真正值得记忆的搭配，如 `tertarik pada`（对……感兴趣）、`mengambil keputusan`（做决定）。
- **词根、词缀与词族**：理解 `makan → makanan` 等派生关系，并查看相关词卡。
- **口语与发音**：认识 `sudah → udah` 等日常表达；使用设备语音朗读印尼语词汇、例句、搭配及口语形式。

## 适合谁？

刚开始学习印尼语、希望积累旅行和日常交流词汇，或希望通过短时间、规律练习建立语言基础的中文使用者。

## 开始使用

1. 打开 **[Bahasa 在线版](https://anna392061.github.io/bahasa/)**。
2. 在首页开始每日新词与复习任务；可以在「设置」调整每日新词数量。
3. 在词卡上先独立回忆，再查看含义、搭配和例句；需要时展开词根与口语说明。
4. 在「词库」中搜索并回看已收录的词。

### iPhone 添加到主屏幕

使用 Safari 打开上面的地址，点击「分享」，选择「添加到主屏幕」。

## 数据与备份

Bahasa 当前是主要依赖浏览器本地存储的 Web App；**学习记录不会因为公开 GitHub 仓库而自动同步到其他设备**。换手机、清除网站数据或使用不同浏览器，均可能导致本地进度无法直接读取。

请使用 App「设置」中的**导出备份**保存学习记录，并在需要时用**导入备份**恢复。离线访问需要先成功加载相应的应用资源。

## 技术信息

静态 HTML、CSS、JavaScript，托管于 GitHub Pages。无需账户即可开始使用；发音依赖设备/浏览器提供的印尼语语音支持。项目持续迭代，词库、表现及兼容性可能变化。
